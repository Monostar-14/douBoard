# douBoard

> 一个支持压感的在线白板

## 快捷键

 - Ctrl+S 导出图片
 - Ctrl+Z 撤回
 - E 橡皮擦
 - B 画笔

## 功能

 - 工具栏「下载」按钮:一键导出为 PNG —— 白底、整块画布全尺寸,与屏幕分辨率一致,保存后可直接分享/插入文档
 - 笔:4 档粗细预设 + 连续粗细滑杆(2–40);色板 12 预设色 + 自选取色器,可任意选色
 - 橡皮:大小滑杆(10–150),擦除范围实时显示
